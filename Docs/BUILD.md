# San Francisco Unity Slice

Unity 6000.5.6f1 procedural vertical slice for a foggy late-afternoon district: modular buildings, traffic, pedestrians, jobs, and a cinematic camera are generated at runtime.

Open the project in Unity 6000.5.6f1 and press Play. The bootstrap creates the playable slice in an empty scene, so no imported art pack is required for the first pass.

## Quality gates

- Project opens with zero compile errors.
- Play mode creates city, traffic, pedestrian, and presentation systems without manual scene wiring.
- Batchmode compilation completes without errors.
- Visual QA checks silhouette, scale, motion, lighting, camera composition, and frame budget.
